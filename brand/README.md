# Arce Signature Group logo

The team logo: two A's, one for each of us, joined by one crossbar so together they form a roofline. Next to it, ARCE in Bodoni over a thin bronze line and SIGNATURE GROUP. All lettering is converted to outlines, so the files look the same on any computer or printer.

## Files
Each file comes as `.svg` (for printers, sign shops and the website; it scales to any size) and `.png` (for social media, email and documents).

| File | Use it for |
|---|---|
| `arce-signature-group-logo` | Main logo, on white or light backgrounds |
| `arce-signature-group-logo-white` | Main logo, on dark backgrounds or photos |
| `arce-signature-group-logo-stacked` (and `-white`) | Square spaces: yard signs, flyers, the top of a page |
| `arce-signature-group-logo-brokerage` (and `-white`) | Ads, social posts, listings: includes "Brokered by DH Capital Realty" |
| `arce-signature-group-mark` (and `-white`) | The double-A on its own: favicon, watermark, embroidery, stamps |
| `arce-signature-group-profile` | Profile picture for Instagram, Facebook and Google |

## Colors
| Name | Hex | Used for |
|---|---|---|
| Charcoal | `#22201d` | Left A, crossbar, lettering |
| Bronze | `#9c7a4f` | Right A and the line under ARCE |
| Light bronze | `#b08d5e` | Bronze on dark backgrounds |
| Bone | `#f6f4f0` | Background, and lettering on dark backgrounds |

For one-color printing (engraving, foil, embroidery), make the whole logo a single color.

## Fonts
- Name: Bodoni Moda (the same font the website uses for headings)
- "SIGNATURE GROUP" and small text: Figtree

## Rules for using the name (Nevada)
- Always write the full name with "Group": **Arce Signature Group**. Never "Arce Signature" by itself, and never add Realty, Real Estate, Properties, Co., Inc. or LLC, so it isn't mistaken for a separate company.
- Every ad, sign and social post must also show **DH Capital Realty** clearly. The `-brokerage` files already include it.
- Every team member must hold a Nevada license with DH Capital Realty.
- Get DH Capital Realty's written approval of the team name and logo before using them.
